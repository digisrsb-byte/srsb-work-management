# What's New

- Automatic desktop updates now use the Electron update engine.
- New versions download automatically in the background.
- The application shows release features before installation.
- Users can choose **Restart & Install** when the update is ready.
- Closing the application normally after an update is downloaded will also install the update.
- React frontend changes are included automatically with every desktop update.
- Backend releases continue to deploy independently through Railway.

> For future releases, replace these bullets with the client-visible features included in that version before creating the version tag.
