# What's New in v1.2.5

- Invoice Print option removed.
- Paid and Outstanding amounts now appear in separate columns.
- Company Settings clearly identifies the email used on invoices as **Invoice Email**.
- Desktop updates download automatically in the background.
- Release features are visible inside the application before installation.
- Users can choose **Restart & Install** once the update is ready.
- React frontend changes are included inside every desktop release.

Backend deployments continue through Railway when `main` is updated.
